添加了"分页模式广告"功能，参考短视频广告的操作流程，为分页模式分类提供专门的广告展示。

## 使用方式

### 后台操作
1. 登录后台管理系统
2. 进入"广告管理"页面
3. 点击"新增"按钮
4. 选择广告类型为"分页模式广告"
5. 填写广告标题、描述、图片等信息
6. 系统会自动设置为全局投放，无需选择分类和位置
7. 保存后，广告会在分页模式分类中展示

### 前端展示
- 分页模式广告会在 `isPagination=1` 的分类页面中展示
- 广告展示模式由分类的 `ad_display_mode` 配置控制：
  - 1: 集中显示（仅第一页顶部）
  - 2: 交替显示（按间隔穿插）
  - 3: 不显示广告
- 广告间隔由分类的 `ad_interval` 配置控制

## 与短视频广告的对比

| 特性 | 短视频广告 (ad_type=5) | 分页模式广告 (ad_type=6) |
|------|----------------------|------------------------|
| 适用场景 | 短视频分类 (isShort=1) | 分页模式分类 (isPagination=1) |
| 投放范围 | 全局投放 | 全局投放 |
| 广告位置 | 不需要 | 不需要 |
| 分类选择 | 不需要 | 不需要 |
| 展示逻辑 | 与视频混合展示 | 与视频混合展示 |
| 后端接口 | `/web/api/advertisement/short-video/{categoryId}` | `/web/api/advertisement/paged/{categoryId}` |

## 技术特点

1. **完整的分层架构**: Mapper -> Service -> Controller
2. **缓存支持**: 使用 Spring Cache 提高性能
3. **前后端分离**: 清晰的 API 接口设计
4. **组件复用**: 复用短视频广告的展示组件
5. **Hook 封装**: 使用自定义 Hook 管理广告状态
6. **响应式设计**: 支持 PC 和移动端展示

## 分页模式广告显示方式调整（2025-12-08）

### 调整说明
分页模式广告的显示方式与短视频广告不同：
- **短视频广告**: 使用网格布局（ShortVideoAdGrid），一次显示15个logo广告
- **分页模式广告**: 使用单个横幅广告（PagedSingleAd），每次只显示一个广告

### 新增/修改文件

#### 1. 新增组件
**文件**: `chigua-web/src/components/PagedCategoryList/PagedSingleAd.jsx`

单个广告展示组件，特点：
- 横幅样式显示
- 自适应宽度
- 包含广告图片和标题
- 支持点击跳转和统计

#### 2. 新增方法
**文件**: `chigua-web/src/services/advertisementService.js`

添加 `createPagedMixedContent` 方法：
```javascript
createPagedMixedContent(videos, ads, adDisplayMode, adInterval = 10, currentPage = 1)
```

**参数说明**:
- `videos`: 视频列表
- `ads`: 广告列表
- `adDisplayMode`: 显示模式（1=集中显示，2=交替显示，3=不显示）
- `adInterval`: 广告间隔，默认10（每10个视频显示一个广告）
- `currentPage`: 当前页码，用于广告轮换

**显示逻辑**:
- 模式1（集中显示）：在列表顶部显示一个广告，根据页码轮换不同广告
- 模式2（交替显示）：每隔N个视频插入一个广告，循环使用广告列表
- 模式3（不显示）：不显示广告

#### 3. 更新组件
**文件**: `chigua-web/src/components/PagedCategoryList/index.jsx`

主要修改：
- 引入 `PagedSingleAd` 替代 `ShortVideoAdGrid`
- 使用 `createPagedMixedContent` 替代 `createShortVideoMixedContent`
- 默认广告间隔从5改为10
- 渲染逻辑支持 `single-ad` 类型

## 注意事项

1. 执行 SQL 脚本前请备份数据库
2. 分页模式广告只在分页模式分类中生效
3. 广告的展示模式由分类配置决定，不是广告本身的属性
4. 修改广告后，缓存会自动刷新
5. **分页模式广告显示为单个横幅样式，不是logo网格**
6. **分页模式默认广告间隔为10个视频，可在分类配置中调整**

## 广告显示对比

| 类型 | 短视频广告 | 分页模式广告 |
|------|----------|------------|
| 组件 | ShortVideoAdGrid | PagedSingleAd |
| 样式 | 3x5网格，15个logo | 单个横幅 |
| 间隔 | 默认5个视频 | 默认10个视频 |
| 轮换 | 循环显示网格 | 单个广告轮换 |
| 适用 | 移动端短视频流 | PC端分页列表 |
