## 🔍 一、百度站长平台

### 访问地址
https://ziyuan.baidu.com

### 提交步骤

1. **注册/登录账号**
   - 使用百度账号登录
   - 如果没有账号，先注册

2. **添加网站**
   - 点击"用户中心" → "站点管理" → "添加网站"
   - 输入网站地址：`https://tycg3.com`
   - 选择网站类型：PC站
   - 验证网站所有权（三种方式选一种）：
     - **文件验证**（推荐）：下载验证文件，上传到网站根目录
     - **HTML标签验证**：在网站首页添加验证代码
     - **CNAME验证**：添加 CNAME 记录

3. **提交 Sitemap**
   - 网站验证通过后，进入"数据引入" → "链接提交"
   - 选择"手动提交" → "提交sitemap"
   - 输入 sitemap 地址：`https://tycg3.com/sitemap.xml`
   - 点击"提交"

4. **查看提交状态**
   - 在"链接提交"页面查看提交状态
   - 通常 24-48 小时内开始抓取

### 注意事项
- ⚠️ 百度对成人内容审核严格，确保 sitemap 只包含主页面和关键词页面
- ✅ 定期更新 sitemap，保持 lastmod 日期最新
- 📊 关注"索引量"和"抓取频次"数据

## 🔧 常见问题

### Q1: 提交后多久会被索引？
**A:** 通常 24-48 小时开始抓取，完全索引可能需要 1-2 周。

### Q2: 如何知道 sitemap 是否被接受？
**A:** 在各平台后台查看提交状态，显示"已提交"或"正常"表示成功。

### Q3: 提交失败怎么办？
**A:** 
- 检查 sitemap.xml 是否可以正常访问
- 检查 XML 格式是否正确
- 检查文件大小是否超过限制（通常 50MB）

### Q4: 需要定期重新提交吗？
**A:** 
- 不需要手动重新提交
- 更新 sitemap.xml 后，搜索引擎会自动抓取
- 建议每周更新一次 lastmod 日期

### Q5: 关键词页面返回 404 怎么办？
**A:** 
- 必须在落地页中实现 `/keyword/{关键词}` 路由
- 可以使用 React Router 或 Nginx 重写规则
- 确保所有 sitemap 中的 URL 都可以正常访问
