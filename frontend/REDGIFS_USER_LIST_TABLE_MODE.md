# RedGifs用户列表 - 改为表格模式

## 修改概述
将RedGifs用户列表从卡片式布局改为标准的表格列表模式，与后台其他列表（如视频管理、分类管理）保持一致的样式和交互体验。

## 主要修改内容

### 1. 布局改变
- **修改前**: 卡片式网格布局 (grid layout)
- **修改后**: 标准Element UI表格布局 (el-table)

### 2. 样式调整
- **移除**: 所有深色主题自定义样式
- **移除**: 卡片相关的CSS样式
- **保留**: Element UI默认表格样式，与后台其他列表一致

### 3. 表格列配置
| 列名 | 宽度 | 说明 |
|------|------|------|
| 选择框 | 55px | 多选框，用于批量操作 |
| 用户头像 | 100px | 显示60px的圆形头像 |
| 用户名 | 自适应 | 显示用户名 + 认证标识 |
| 描述 | 自适应 | 显示用户描述信息 |
| 统计信息 | 280px | 显示视频数、观看数、粉丝数 |
| 创建时间 | 160px | 格式化显示时间 |
| 状态 | 180px | 启用/禁用切换开关 |
| 操作 | 150px | 查看视频、删除按钮（固定在右侧） |

### 4. 功能保留
所有原有功能均保留：
- ✅ 搜索功能（用户名、状态、认证状态）
- ✅ 批量删除
- ✅ 状态切换（启用/禁用）
- ✅ 单个删除
- ✅ 点击"查看视频"进入用户视频列表
- ✅ 分页功能

### 5. 数据展示优化
- 头像使用 `el-avatar` 组件，支持默认占位图标
- 认证用户显示绿色"已认证"标签
- 统计信息使用三种颜色的标签区分：
  - 视频数：蓝色 (primary)
  - 观看数：灰色 (info)
  - 粉丝数：橙色 (warning)
- 时间显示格式：`YYYY-MM-DD HH:mm:ss`
- 数字格式化：1K, 1M等简化显示

### 6. 代码优化
- 简化 `handleSelectionChange` 方法，使用表格的selection参数
- 移除卡片选中状态管理（`selected` 字段）
- 添加 `parseTime` 方法用于时间格式化
- 保留 `formatNumber` 方法用于数字格式化

## 修改文件
- `frontend/src/views/chigua/redgifs/user/index.vue`

## 效果对比
- **修改前**: 深色主题、紫色强调色、卡片式布局
- **修改后**: Element UI标准样式、表格式布局、与后台其他页面统一

## 兼容性
- 保持与后台其他列表页面一致的用户体验
- 适配所有屏幕尺寸
- 支持所有现有功能
